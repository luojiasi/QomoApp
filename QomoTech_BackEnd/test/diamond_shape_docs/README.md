## 重要结论（读文献时）

1. **比例 ≠ 绝对尺寸**：L/W、台宽%、深度% 都是相对量；真要切，还要毫米级腰长/腰宽（或克拉体积模型）。
2. **AGS 与 IGI 侧重点不同**：AGS 偏光性能射线追踪；IGI 给的是「历史上好看石头常见的比例窗 + 目视回光」。
3. **雷迪恩 ≠ 祖母绿**：外轮廓都可切角矩形，但刻面族不同；雷迪恩看 Grossbard 专利，祖母绿看 AGS naming + 阶梯角。
4. **公主方不在图里**，但 AGS Ideal Report / IGI 都有 Princess 条目，需要时可另下。
